下一步不是加更多 AI agent —— 是把这一条链变成可验证的

30 天 → 90 天 → 120 天 · 时间轴按真实天数等比 · 明度 = 确定性（越黑 = 越近越确定）· 每段两组数字：COLLECT = 要收多少，GATE = 过什么线，不过线不进下一段
DAY 0–30 · GATE 1

Validate the engines

不加功能，只加证据。产出是一套能重复跑的评测。

  • 150 份人工标注 resume（100 调优 / 50 holdout 永不参与调优）
    来源：Talentbank 已同意样本 + 校园招募，逐份 consent
  • Malaysia source registry：每个来源记许可、时效、样本量
  • Eval harness + model / prompt registry，任一历史分数可 replay

citation < 99% → 回去修抽取，本阶段一个分数都不发布。

DAY 31–90 · GATE 2

Partner beta

接真实雇主，回路第一次真的转起来。范围锁死 3 个 role family。

  • Talentbank employer feed + 5 家雇主签约试用
    JD 与 outcome 均来自 approved feed，不 scrape
  • Reason code 定稿（8–12 个）+ certificate verification
  • Queue autoscaling + DLQ：失败从最后成功 stage 续跑
COLLECT · 要收多少
签约雇主≥5
真实 JD≥200
候选人≥300
OUTCOME≥150
GATE · 质量门槛
二次使用3/5
CERT 解析≥90%
BAND 覆盖≥80%
ROLLBACK

outcome < 50 → 不发任何 aggregate，延长 beta。绝不调低 cohort threshold 换 signal。

DAY 91–120 · GATE 3

Calibrate & harden

第一次用真实结果回看分数，同时把系统撑住。

  • 用已有 outcome 做第一次 calibration 读数（不是最终结论）
  • Drift monitoring + 去标识化 warehouse（0 个 PII 列）
  • HA / DR 在 ap-southeast-5 真跑一次恢复演练
COLLECT · 要收多少
有后续结果的人≥150
累计 OUTCOME≥250
GATE · 质量门槛
校准误差≤10pp
DR 演练≥1
PII 列0
ROLLBACK

误差 > 15pp → 撤下数值分数，只显示定性区间与证据清单。
